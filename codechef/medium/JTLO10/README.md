Given a string $S$, generate and print all possible non-empty subsequences of the string.

A subsequence is formed by deleting zero or more characters from the string without changing the order of the remaining characters.

### Input Format
- The first line contains a string $S$.
### Output Format

Print all possible non-empty subsequences of $S$, one per line.

The subsequences can be printed in sorted order.

### Constraints
- $1 \le |S| \le 20$
- $S$ contains lowercase English letters or numbers (1-9) only.
